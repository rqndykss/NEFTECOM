# АЗС НЕФТЕКОМ

## Описание

Веб-проект, разработанный с использованием HTML, CSS и JavaScript.

* JavaScript

* CSS Grid
* Yandex Maps API

## Функциональность

* Работа с интерактивной картой через Yandex Maps API
* Адаптивная верстка находится в разработке
* Использование Flexbox и Grid для построения интерфейса
* Динамическое взаимодействие элементов через JavaScript
