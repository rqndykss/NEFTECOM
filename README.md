# АЗС НЕФТЕКОМ

## Описание

Веб-проект, разработанный с использованием HTML, CSS и JavaScript.

## Используемые технологии

![HTML5](https://img.shields.io/badge/html5-%23E34F26.svg?style=for-the-badge&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/css3-%231572B6.svg?style=for-the-badge&logo=css3&logoColor=white)
![JavaScript](https://img.shields.io/badge/javascript-%23F7DF1E.svg?style=for-the-badge&logo=javascript&logoColor=black)
![Yandex](https://img.shields.io/badge/Yandex_API-%23ff0000.svg?style=for-the-badge&logo=yandex&logoColor=white)

* HTML5
* CSS3
* JavaScript
* Flexbox
* CSS Grid
* Yandex Maps API

## Функциональность

* Работа с интерактивной картой через Yandex Maps API
* Адаптивная верстка находится в разработке
* Использование Flexbox и Grid для построения интерфейса
* Динамическое взаимодействие элементов через JavaScript
